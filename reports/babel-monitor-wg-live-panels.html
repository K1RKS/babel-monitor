SectionSourceFilter
WireGuard Original node↔node tunnels (wgc* / wgs*, UCI wireguard client+server) bm_wg_sc_enabled_only (default on)
WireGuard Mobile WG-M peers (wgm*, UCI wireguard_mobile) bm_wg_m_enabled_only (default on)

No third table — servers and clients share the WireGuard table (Role column).

Architecture

collectSample()
  ├─ pushSample(sample)          ← ring UNCHANGED
  ├─ store.live_neighbors = …
  ├─ store.last.wg_xfer = {…}    ← scratch for rate Δ (not ring)
  └─ store.wg = {
       server_tunnels / clients / mobile: {live,active,total},
       sc: [ … ],
       mobile_peers: [ … ]
     }
Versioning Bump API_VERSION only. Prefer one wg show all dump parse per sample; cap rows (~64).

UI columns (v1)

WireGuard (original tunnels)

  • Name · Role · Last heard · Status · RX/TX (lifetime) · RX/TX rate · MTU · Contact · Port

WireGuard Mobile

  • Name · Est. (icon) · Last heard · Status · RX/TX · RX/TX rate · MTU · Notes · Address · Port
Established (filled) Not established (unfilled)

Tooltip on Est.: “First claim used — not live connection.” Live status stays a separate column.

Rates & bytes

  • Lifetime RX/TX from wg — tooltip “since iface/peer up”.
  • RX/TX rate from store.last.wg_xfer deltas over the sample interval (first sample after appear = —/0).
  • True rolling 24h totals out of scope (would need ring/flash).

MTU & notes

  • SC: mesh wireguard network MTU / iface when available.
  • WG-M: resolved effective MTU (last_mtu / fixed / default / sysfs).
  • SC Contact = UCI contact; WG-M Notes = UCI notes.

Later extras (optional)

  • Endpoint · Allowed IPs · Keepalive · Aggregate live bytes on KPI
